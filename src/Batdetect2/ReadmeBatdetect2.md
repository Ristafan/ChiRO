# Batdetect 2
https://github.com/macaodha/batdetect2?tab=readme-ov-file

## Summary
Aodha introduces  bounding boxes with information about start and end time, min and max frequency and species probability that are used as annotations. A one-stage object detection method CNN encoder-decoder architecture with a self-attention layer in between that is only operating along the temporal dimensions, ensure computational efficiency while producing more easily interpretable results for humans. The paper shows that the model pipeline works well for audio data from different regions of bats and the increase of the model performance when including self-attention for increasing input sizes. The manual annotation of the training data has been made easier by implementing a UI but is still a time consuming factor that limits the scalability of the model.
